## Prerequisites

| Item | Specification | Notes |
| --- | --- | --- |
| 3D Printer | FDM (0.4 mm nozzle) | PLA or PETG |
| Controller | Microcontroller board | See electronics guide |
| Firmware | Latest release | Built via CLI |

## Next Steps

1. Print the mechanical components listed in the bill of materials.
2. Wire the electronics according to the schematic diagram.
3. Flash the firmware and run the calibration checklist.
