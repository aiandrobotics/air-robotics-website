Welcome to this standalone **Air Robotics** documentation template.

## Features

- Runs standalone with `pnpm --dir docs dev` using the shared `@air-robotics/docs-theme`.
- Publishes automatically into `air-robotics.ai` at `/docs/<slug>/` when registered in `robots.yaml`.
- Fully responsive across mobile, tablet, and desktop screens.

Continue to [Getting Started](./getting-started/).
